# 数据统计报告（B：格律引擎与数据）

> 版本 v1.0 / 2026-11-27　数据：全唐诗 57,969 首（含《唐诗三百首》重复收录）
> 复现命令见文末 §9。所有数字都由脚本直接产出，没有手抄。

## 1. 结论摘要

| 项 | 结果 | 说明 |
|---|---|---|
| 语料规模 | 56,207 首 / 3,033,564 汉字 / 3,882,387 tokens | 去重后，含标点与换行 |
| 词表 | 6,466（`min_freq=3`） | 含标点与换行；要 ~5000 需 `min_freq=10`（见 §3.3） |
| 切分 | 90.0% / 5.0% / 5.0%（按作品） | train 50,586 / val 2,810 / test 2,811 首 |
| 平水韵表 | 106 部 / 9,485 字 / 11,926 条 | 30 平声部、76 仄声部；多音字 1,011 |
| 未收录字 | 723 种 / 1,645 次 / **0.054%** | 占字次比例，长尾扩展区字 |
| 格律引擎体检 | 五律 74/83（89.2%）、五绝 14/33（42.4%） | 唐诗三百首按体裁标签；失败多为古绝/拗律 |
| 全唐诗 4 句×5 字 | 3,782 首，合律 2,007（53.1%） | 其中平韵作品内合律率 **95.0%** |

两个容易踩的坑已经修掉，写在这里提醒后续接手的人：

1. **`paragraphs` 是"联"不是"句"**。`"秦川雄帝宅，函谷壮皇居。"` 一条 paragraph 里含两句，
   必须按标点拆句，否则五绝会被算成"4 句 × 10 字"。
2. **异体字不是繁简问题**。`疎/疏`、`劒/剑`、`猨/猿` 这类字 opencc 的 `t2s` 不转换，
   语料里占约 1% 字次，不归一化就会在韵表里查不到。

## 3. 处理流程与规模

### 3.1 流程

```
读 JSON → 按作品聚合（拆联为句） → 繁转简（opencc t2s） → 异体字归一（372 条映射）
      → 两级去重 → 按作品切分 90/5/5 → 建字表（min_freq=3） → uint16 落盘
```

### 3.2 去重

| 阶段 | 数量 |
|---|---|
| 原始作品 | 57,969 |
| 太短丢弃（< 10 字） | 402 |
| 完全重复（整首文本相同） | 1,309 |
| 近似重复（去标点后相同） | 51 |
| 保留 | **56,207** |

完全重复主要来自《唐诗三百首》与全唐诗的重叠，以及全唐诗自身跨卷重收。

### 3.3 词表

| `min_freq` | 3（已采用） | 8 | 10 | 15 |
|---|---|---|---|---|
| 词表大小 | **6,466** | 5,326 | 5,077 | 4,643 |

工作说明 §3.1 写的 vocab_size ≈ 5000 是估计值；实测 `min_freq=10` 才到 5,077。
本次取 `min_freq=3` 以保住长尾字（模型只有 3M 参数，embedding 占比不低，
若显存/收敛有问题，把 `--min-freq` 调到 8~10 即可回到 ~5000）。

### 3.4 切分与产物

| 文件 | 作品数 | 汉字 | tokens |
|---|---|---|---|
| `data/processed/train.bin` | 50,586 | 3,450,967 | 3,501,553 |
| `data/processed/val.bin` | 2,810 | 184,771 | 187,581 |

`meta.json` 除 `vocab_size` / `itos` 外附带 `seed`、`min_freq`、去重计数，便于追溯；

## 4. 语料构成

### 4.1 句长分布（558,102 句）

| 句长 | 5 字 | 7 字 | 4 字 | 6 字 | 3 字 | 其他 |
|---|---|---|---|---|---|---|
| 句数 | 329,061 | 161,472 | 19,996 | 6,972 | 15,924 | 24,677 |
| 占比 | 59.0% | 28.9% | 3.6% | 1.2% | 2.9% | 4.4% |

五言为主，符合"全唐诗 + 五绝"的目标；七言也不少，可作为后续扩展。

### 4.2 平仄分布（按字次）

| 平 | 仄 | 平仄两读 | 未收录 |
|---|---|---|---|
| 1,225,929（40.4%） | 1,361,324（44.9%） | 444,666（14.7%） | 1,645（0.05%） |

平仄两读占 14.7%，主要是多音字（中/看/思/长）。判定时"两读"按两种读法都接受，
取舍留给解码期的上下文（见 §5.2）。这也解释了为什么合律率统计会略偏宽松。

### 4.3 高频字（前 20）

`不 人 一 无 山 风 日 云 有 天 来 中 何 上 时 为 水 花 月 春`

### 4.4 未收录字（查不到平仄）

723 种 / 1,645 次 / 0.054%，前几位：`𣃁(77) 𫛶(61) 𬸦(35) 䍠(28) 𫛛(25) 鷰(24) 皐(19)`。
绝大多数是 CJK 扩展区字与极罕见异体字，常用字覆盖率是完整的。
`check()` 遇到未收录字会明确报"未收录平水韵"，不会静默当平声处理。

### 5.2 判定口径（答辩会被问）

| 规则 | 本项目的做法 | 理由 |
|---|---|---|
| 平仄来源 | 平水韵表中古音，**禁用 pypinyin** | 入声字（白/国/竹/石）普通话读平，中古属仄 |
| 多音字 | 平仄两读都接受 | 判定器没有上下文，硬挑一个读音会误杀真诗 |
| 孤平 | 平收句中除韵脚外只剩一个平声、且不与韵脚相邻 | 王力口径；"仄仄仄平平"第三字与韵脚相连，不算孤平 |
| 三平调 | 句末三字**确定**读平才算 | 多音字（如"不"）不能凑数，否则《王孙归不归》被误判 |
| 出韵 | 按 106 部严格同部 | 东/冬、支/齐 等邻韵通押一律判出韵（唐人不严、平水韵严） |
| 一三五不论 | 只在 `strict=False` 放开第 1、3 字 | 模板永远存严格值，放宽在 `check_line` 做（§7.1） |
| 特拗 | `PPPZZ → PPZPZ`，默认关闭，可显式开启 | 唐诗高频，但"同一首诗里混用"会影响合律率统计口径 |

### 5.3 韵部频率（全唐诗 2,007 首合律五绝的韵脚）

| 韵部 | 四支 | 十一真 | 八庚 | 七阳 | 十一尤 | 一先 | 一东 | 十灰 | 五微 | 六麻 |
|---|---|---|---|---|---|---|---|---|---|---|

## 6. 判定器体检

### 6.1 唐诗三百首（人工选本，带体裁标签）

| 体裁 | 判定合律 | 说明 |
|---|---|---|
| 五言绝句 | 14 / 33（42.4%） | 失败的全是仄韵古绝或拗绝 |
| 五言律诗 | 74 / 83（89.2%） | 9 首失败均为拗律或孤平，属真实违律 |

抽查失败样本（每首都能指到具体规则）：

| 诗 | 判定理由 | 人工结论 |
|---|---|---|
| 《春晓》 | 第 2、4 字平仄不合、第 2/4 句韵脚"鸟/少"非平声 | 仄韵古绝，判掉正确 |
| 《江雪》 | 平仄不合 + "绝/灭/雪"仄韵 | 仄韵古绝 |
| 《鹿柴》 | 第 2 句第 4、5 字平仄不合 | 仄韵古绝 |
| 《静夜思》 | 第 2 句孤平 | 古绝 |
| 《听弹琴》 | 第 2 句三平调（"松风寒"） | 古绝 |
| 《行宫》 | 出韵："宫/红(一东)、宗(二冬)" | 东冬通押，平水韵判出韵 |
| 《望洞庭湖赠张丞相》 | 第 1 句孤平（"八月湖水平"） | 拗律，真违律 |

### 6.2 全唐诗中 4 句 × 5 字作品（3,782 首）

| 指标 | 结果 |
|---|---|
| 合律 | 2,007（53.1%） |
| 韵脚类型 | 平韵 2,113 / 仄韵 611 / 混或不齐 1,058 |
| 平韵作品内合律率 | **95.0%** |

**53.1% 不代表引擎差**：全唐诗里"四句五言"有大量乐府、古绝、摘句，它们本就不合近体。
把范围收到"押平韵"的作品后合律率 95.0%，剩余 5% 是拗律、孤平、未收录字。
这个数字是 M2 验收"`check()` 对真实唐诗判定正确"的直接证据。

### 6.3 格式分布（2,007 首合律五绝）

| 首句 | 数量 | 占比 | 首句入韵 |
|---|---|---|---|
| A（仄起不入韵） | 1,327 | 66.1% | 否 |
| C（平起不入韵） | 468 | 23.3% | 否 |
| D（仄起入韵） | 153 | 7.6% | 是 |
| B（平起入韵） | 59 | 2.9% | 是 |

首句入韵仅 212 首（10.6%），与"首句入韵更常见"的直觉相反——数据支持
"五绝以仄起不入韵为主"。`sample` 策略按此频率加权即可。

## 7. 已知问题与限制

| # | 问题 | 影响 | 处理 |
|---|---|---|---|
| 1 | 723 种罕见字查不到平仄 | 判定报"未收录" | 如实报错；不猜读音 |
| 2 | 两表 1,352 处分歧未逐字裁决 | 极少数冷僻字平仄可能反 | 清单已导出，采用主表；冲突集中在多音字 |
| 3 | 平水韵口径偏严（邻韵通押判出韵） | 部分唐人作品判不合律 | 保留严格口径，报告里如实说明 |
| 4 | 五律只判平仄与韵，不判对仗 | 对仗不工的五律会被判合律 | 对仗判定在范围外（§1.4） |
| 5 | 古体诗与近体诗混在同一语料 | 模型学到的分布较杂 | 词表/切分不变；生成时由模板约束兜底 |
| 6 | `.gitignore` 原来只有一行 `data` | `prosody/data/*.json` 会被整目录忽略，韵表进不了 git | 已改成 `/data/raw/`、`/data/processed/`、`/out/` |

另：仓库里 `prosody/__pycache__/*.pyc` 目前被 git 跟踪着（历史遗留），
`.gitignore` 只对未跟踪文件生效，需要 `git rm --cached` 才能清掉——这属于 git 历史操作，
留给仓库管理员决定。

## 9. 复现命令

```bash
# 1. 语料（25.8 MB，不进 git）
python data/download.py

# 2. 格律引擎的数据文件
python prosody/data/build_pingshui.py            # 需要语料；无语料时退化为不补字
python prosody/data/build_variants.py --unihan Unihan_Variants.txt   # 可选：叠加 Unihan

# 3. 数据管线
python prepare.py --raw data/raw --out data/processed

# 4. 测试与体检
python -m unittest discover -s tests
python tests/benchmark_real.py
```

与 C 对接的接口见工作说明 §6.1；`check()` 的额外关键字参数
（`allow_teao` / `allow_gujiu`）默认关闭，C 启用特拗时要同步打开，否则判定与 mask 不一致。
